Política de Privacidade

O CorteViral é um aplicativo que roda localmente no computador do usuário. Não existe servidor do CorteViral: nenhum dado é enviado para nós.

Dados acessados

  • YouTube (Google): nome e ID do canal e permissão para enviar vídeos (escopo youtube.upload) e ler os dados do canal (youtube.readonly).
  • TikTok: informações básicas do perfil (open_id, nome, avatar) e permissão para enviar vídeos (video.upload, video.publish).

Como os dados são usados

Somente para publicar, nos horários escolhidos pelo usuário, os vídeos que ele mesmo aprovou, e para mostrar no app qual conta está conectada.

Armazenamento e compartilhamento

Os tokens de acesso ficam salvos apenas no computador do usuário (arquivos locais do app). Eles não são vendidos, compartilhados nem enviados a terceiros, exceto às próprias APIs do Google/YouTube e do TikTok no momento da publicação.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como remover o acesso

  • No app: Contas → Remover.
  • Google: myaccount.google.com/permissions.
  • TikTok: Configurações e privacidade → Segurança → Apps e serviços.

Ao remover, os tokens deixam de funcionar e o usuário pode apagar os arquivos locais do app a qualquer momento.
